💻 Portafolio de Desarrollador de Software

Portafolio personal desarrollado con Angular y TypeScript para presentar mi perfil profesional, habilidades técnicas y proyectos de desarrollo de software.

Mi enfoque principal es el desarrollo backend con C# y .NET, creando APIs REST y aplicaciones estructuradas con buenas prácticas de programación. Este portafolio reúne mis proyectos y demuestra mi experiencia práctica en el desarrollo de software.

🚀 Tecnologías utilizadas

Angular: Desarrollo de la interfaz de usuario.

TypeScript: Lógica y tipado de la aplicación.

HTML5: Estructura y contenido.

CSS3: Estilos y diseño adaptable.
